# Security Policy

## Reporting Security Vulnerabilities

If you identify a security issue or vulnerability in IIDS, please report it directly to the maintainers rather than opening a public issue.

**Security Contact**: adityamishra0578@gmail.com

Please include:
- A brief description of the vulnerability.
- Steps to reproduce or proof-of-concept payload.
- Affected endpoint or module.
- Any suggested remediation.

Reports are reviewed promptly and acknowledged within 48 hours.
